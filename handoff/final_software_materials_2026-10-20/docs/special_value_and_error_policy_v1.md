# 特殊值与错误策略：待双方确认的 v1 草案

当前已经逐位覆盖的证据范围是有限 FP32 输入、正负零、次正规数和舍入边界。NaN、Inf 以及中间/最终溢出尚未纳入正式联合验收。

建议在正式冻结前确认：

1. NaN/Inf 是禁止输入并由软件预检，还是由 RTL 检测并置 ERROR。
2. 溢出采用 IEEE 无穷、饱和、还是 ERROR。
3. 正负零、次正规数是否要求逐位保持。
4. 总线错误或读响应超时后，DMA 是否立即停止，ERROR 是否 sticky，如何复位恢复。
5. ERROR 与 DONE 同时出现时，软件必须优先按 ERROR 处理。

在这些规则确认前，`ERROR=0` 不能解释为所有特殊值均已支持。
