# KWT-1 前馈线性层 AI 加速器

**交接快照：2026-10-23。**项目面向 2026 年嵌入式芯片与系统设计竞赛芯片设计赛道本科生组。目标是在指定 E203 平台上加速 KWT-1 编码层的第一层前馈线性计算：

```text
Y[99,256] = X[99,64] × W[64,256] + bias[256]
```

模型有 12 个编码层；首版数值路线为 FP32。本文把**软件参考计算、归档 RTL 功能验证、真实 SoC 集成、综合及物理指标**分开陈述。任何单层仿真通过都不等于整机或 12 层推理完成。

## 综合接入时先拿什么

1. **确定同一版设计。**向硬件同学索取综合专用 RTL 提交或完整源码快照及 SHA-256、综合顶层、filelist、宏定义和参数。2026-10-23 真实模型仿真包保存了 RTL/testbench/filelist 的 41 项源码指纹，但其来源目录不是 Git 工作区，因此没有可直接核实的 RTL Git 提交号。不要把旧的 `hardware`/`integration` 分支快照自动等同于这份归档。
2. **确定同一组输入和正确性基线。**软件真实模型 layer 00 输入包 `kwt1-real-ffn1-layer00-handoff-2026-10-23.zip` 的 SHA-256 是 `5504f7b2e77be9350cc6da40d4a122d892084486d5b57cd0553ffb9550ff8147`；硬件归档包 `real_ffn1_layer00_rtl_2026-10-23.zip` 的 SHA-256 是 `86238127a80a2f1726d9968698c57a676dd065f9419dde69988dfe07cfdd4db20`。两包含模型数据、音频或仿真产物，**不作为普通源代码提交到 Git**；需由持有人单独交付原包，校验哈希后使用。源文件和对应检查范围见[真实模型验收报告](reports/KWT-1_真实模型第0层RTL独立验收_2026-10-23.md)。
3. **先统一度量口径。**记录工具版本、工艺库与角点、时钟/复位约束、SRAM 是宏还是行为模型、面积是否计入 SRAM、功耗活动文件及任务起止窗口。对同一源码和输入分别报告功能、综合、时序、面积、功耗，保留命令、日志及来源哈希。已有[综合交接说明](docs/KWT-1_最终交接汇报_给综合同学_2026-10-17.md)是 10 月 17 日历史起点，其中“尚无 FP32 整层”等状态已过时；当前状态以本页和最新验收报告为准。
4. **明确平台缺口。**内部示例字地址不是 E203 物理地址。NICE/System Bus 接线、实际地址窗口、寄存器映射、DONE 后 CPU 可见性及异常处理，需以硬件/平台方当前合同和实测为准；软件仓库的抽象驱动不能直接当成板上驱动。[FP32 接口确认单](docs/KWT-1_FP32_接口确认单.md)保留候选项及待签字段。

## 仓库结构与基本检查

| 路径 | 用途 |
| --- | --- |
| `software/` | 模型提取、FP32 参考、数据打包、轨迹/输出比较、抽象驱动和测试；从[软件说明](software/README.md)开始。 |
| `rtl/`、`tb/`、`soc/` | 硬件 RTL、仿真和平台集成；在不同分支/交付包中的实际内容，以所选固定版本为准。 |
| `synthesis/` | 综合脚本及 PPA 工作区；报告必须绑定确定源码、库和约束。 |
| `integration/` | 仓库基础检查及团队集成。 |
| `docs/`、`handoff/`、`reports/` | 合同草案、交接材料与有边界的验收报告。 |

在仓库根目录运行基础检查：

```powershell
python integration/check.py
```

该命令只检查它实际执行的基础项目；退出码 0 **不代表**真实 RTL、SoC 或 PPA 验收通过。软件工具的用法和输入格式见 [`software/README.md`](software/README.md)。`.gitignore` 排除模型、音频、ZIP、EDA 产物、工艺库和本地环境；需要复核的外部材料请走独立交付并记录 SHA-256，不要用全量 `git add` 把原始证据包带入仓库。

早期 [`docs/PROJECT_STATUS.md`](docs/PROJECT_STATUS.md) 和 [`docs/SUBMISSION_CHECKLIST.md`](docs/SUBMISSION_CHECKLIST.md) 记录的是建仓阶段与通用清单，**不是 2026-10-23 的进度结论**。任何新验收应追加带日期、来源和明确范围的报告，保留历史失败记录。
