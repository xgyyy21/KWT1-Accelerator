# memory_layout_v2：硬件内部存储布局合同

## 范围和状态

这是拿到真实 E203 地址窗口前的硬件内部版本。地址字段使用 **16 位字地址**，一个地址对应一个 16-bit SRAM word；它不是最终平台物理地址合同。

共享 SRAM 总容量按 512 KiB 计算，即 `262144` 个 16-bit word。FP32 每个数拆为两个连续 word，低 16 位在前，高 16 位在后。矩阵统一使用行主序。

## 建议区域

| 区域 | 基地址（word） | 容量（word） | 逻辑内容 |
|---|---:|---:|---|
| X | `0x00000` | `12672` | `99 x 64 x 2` |
| W | `0x04000` | `32768` | `256 x 256 x 2` |
| bias | `0x0C000` | `512` | `256 x 2` |
| Y | `0x10000` | `50688` | `99 x 256 x 2` |

这些区域互不重叠并保留了后续扩展空间。当前 RTL 的 base 寄存器仍允许软件配置，不能把这些数字当成比赛最终物理地址。

## 地址公式

令 `half=0` 表示低 16 位，`half=1` 表示高 16 位：

- `X[row,k,half] = X_BASE + 2 * (row * K + k) + half`
- `W[k,col,half] = W_BASE + 2 * (k * N + col) + half`
- `bias[col,half] = BIAS_BASE + 2 * col + half`
- `Y[row,col,half] = Y_BASE + 2 * (row * N + col) + half`

## 16 位 SRAM 约束

- 每次只读或写一个 16-bit word；禁止把 32-bit FP32 访问直接接到 SRAM 宏。
- 一个 FP32 传输必须拆成低半字、高半字两个传输。
- 每个 SRAM bank 每拍最多一个操作。
- 请求未被接受或读响应未返回时，valid、地址和写数据保持不变。
- 复位不清空 SRAM 内容；standby 与 retention 的控制含义不能混用。
