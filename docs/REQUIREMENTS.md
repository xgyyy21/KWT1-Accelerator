# 官方关键要求与验收清单

依据：根目录 `嵌赛题目.pdf`，本地逐页图像核对，未以交接文档代替官方。该文件为扫描件，13 个物理页对应印刷第 2～14 页；下文页码均指印刷页。印刷第 1 页缺失，版本完整性及最新更正须向老师/竞赛平台确认。本阶段未访问外部链接、下载模型或核验远端版本。

## 必做功能（印刷 4～8 页）

- [ ] 任务 1：可综合 Verilog/SystemVerilog，实现长度 64 点积、偏置及所需数值转换；验证正常数据、边界、复位和连续任务，说明舍入、溢出和误差。
- [ ] 任务 2：实现 `Y[t,j]=b[j]+sum(k=0..63) X[t,k]W[k,j]`，输入 99×64、权重 64×256、输出 99×256；参数装载、输入缓冲、控制和写回齐全；指定权重和对应层输入验证，依次更换 12 层参数。
- [ ] 任务 3：接入指定 E203，完成驱动、格式转换、启动/完成管理及 SoC 仿真；完成综合，提供 RTL、测试平台、网表、时序约束、面积/功耗报告及周期/吞吐记录。
- [ ] 必做数值计算由硬件执行，CPU/测试平台不能代算；GELU、第二线性层、注意力不属于本科必做。自主创新先完成任务 1～3，再由团队选定，不在本阶段实施。

## 指定模型与数据（印刷 4～7 页）

- [ ] 使用 `ARM-software/keyword-transformer` 提交 `237e4097`，目录 `models_data_v2_12_labels/kwt1` 及 `best_weights`；推理模式，关闭训练、随机增强及 Dropout。不得重训练、微调、蒸馏或改变层数/维度/基本运算结构；允许无梯度标定与格式转换。
- [ ] 数据为 Google Speech Commands V2（speech_commands_v0.02），按指定源码划分/映射/预处理；训练划分用于无梯度标定，验证划分用于调试/验证，测试划分不能调权重、量化参数或数值配置。
- [ ] 1 秒、16 kHz 单声道；离线生成 98×40 MFCC、投影/token/位置编码等不计硬件任务。模型为 12 层、特征 64、单头、FFN 64→256→64、PostNorm；单任务批量 1。
- [ ] 本科离线提取每层注意力、残差及第一处 LayerNorm 后的 FFN1 输入、对应 W/b 与浮点参考输出。正式评测为组委会统一选取 600 样本，结束后公布清单，不另发预处理数据包；提交冻结工程和数值配置。

## 平台、精度与计量（印刷 3～4、10～12 页）

| 验收点 | 官方边界 / 后续所需证据 |
|---|---|
| 平台 | 指定 E203、总线及外设工程；AI Engine 通过 System Bus 或 NICE 接入（团队待选）。512 KB 共享 SRAM，分层装载，不增 DDR/外部存储控制器 |
| 内部 SRAM | 指定 16 bits×128 / ×1024 / ×4096 单端口或双端口宏组合；容量由团队依面积/效率决定。三块 16×1024 为硬件回复中的老师约束转述，不是官方唯一组织 |
| 数值协议 | 官方允许定点、浮点或混合；位宽、尺度、舍入、饱和、运算顺序由团队确定。本阶段不冻结 FP32/INT16 |
| 精度 | 各层在全部评测样本上汇总：`NRMSE_l = RMS(Y_decoded-Y_float) / max(RMS(Y_float), 1e-8)`；12 层最大值 ≤ 3%，全部解码结果有限。不得平均各样本比值代替层汇总 |
| RTL 一致性 | 规定的 12 个性能任务和独立组件向量上，RTL 与提交的软件数值模型逐位一致；这与浮点参考误差是两项不同验收 |
| 时序 | 系统和综合目标 150 MHz（周期约 6.6667 ns，仅目标）；提供有效约束、关键路径、裕量和综合前后功能检查，不能隐藏违例 |
| 计时 | 本科一任务=一次规定 FFN1 并写回；组委会选覆盖 12 层的 12 次线性任务，每次单独满足 3%。任务前清空任务数据/参数缓存；从输入与参数开始装载到所有结果写回结束，包括装载、总线等待、E203 调度；任务间平台复位不计入。热缓存实验不能冒充官方成绩 |
| 吞吐/能耗 | 吞吐=完成任务数/总时间；能耗=平均功耗×总时间/任务数；不含 PC 预处理、一次性格式转换及统一软件分类头 |
| 功耗 | 同计时窗口 SAIF/VCD，同一库、角点、负载、时钟与互连估计；统计 E203、加速器、互连、SRAM 动/静态功耗，模拟及片外不计。活动映射/覆盖检查，不将未标注电路视为零活动，SRAM 不能零功耗 |
| 面积 | 新增加速器+接口逻辑+内部 SRAM 宏 ≤ 2.25 mm²。标准单元按指定库综合映射，SRAM 按官方宏面积；复用 E203、共享 512 KB SRAM、固定总线/外设不计预算但单列。不能遗漏或重复计数 |
| 一致配置 | 吞吐、功耗、面积来自同一冻结配置/网表；通过必做功能、数值、RTL 对照、时序及面积门槛后才评效率/创新。无需布局布线、物理验证或流片 |
