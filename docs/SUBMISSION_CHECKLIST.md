# 正式提交材料清单

来源：根目录官方 PDF 印刷 7～8、13～14 页；评估口径见 10～12 页。本阶段只整理清单，以下正式成果均未生成/验收。具体提交平台、命名、大小限制和日期以竞赛通知为准。

## 官方明确要求

| 阶段 | 应交材料 | 主责 | 当前证据 |
|---|---|---|---|
| 初赛 | 本科必做任务 1～3 的 RTL | 硬件 | 未随附 |
| 初赛 | E203 驱动、验证工程（含测试平台/SoC 验证） | 软件+硬件 | 未随附 |
| 初赛 | 综合报告 | 统筹 | 未执行；不能以目录或脚本代替 |
| 两阶段 | 数值格式说明、与 RTL 一致的软件数值模型、参数转换脚本 | 软件+硬件 | 未冻结，代码未随附 |
| 任务 3 / 决赛 | 综合网表、时序约束（SDC）、面积及功耗估算报告、任务周期和吞吐量记录 | 统筹 | 依赖工具、库、RTL 与真实任务 |
| 决赛 | 全部必做成果及自主选做成果、可复现工程 | 三人 | 必做未验收；创新未决定 |
| 决赛 | 功能与时序报告、面积报告、SAIF/VCD 及功耗报告、吞吐与能耗记录 | 硬件+统筹 | 尚无实测，不能预填成绩 |
| 决赛 | 创新对照实验及答辩材料 | 三人 | 未安排，按实际选做成果准备 |
| 决赛 | 模型、数据、脚本、工具配置的版本与校验值 | 各成果负责人 | 当前仅原材料哈希在基础报告记录 |
| 全部设计 | 设计来源及引用说明、自主设计部分标识 | 三人，统筹汇总 | 待源码及引用到位 |

不提交伪造网表、测试截图、时序/面积/功耗或精度数据。正式报告须对应同一冻结工程。SAIF/VCD、模型/数据等虽被 `.gitignore` 排除，正式交付仍应按官方要求另行打包并给来源/哈希；受限库不可擅自公开。

## 团队为开发与验证增加（非官方指定文件名）

- README、CONTRIBUTING、交接模板、状态表、要求清单、本清单、基础检查程序与 Markdown/JSON 报告。
- 后续经确认的数值/存储/控制协议、唯一顶层及编译顺序、输入输出 manifest、哈希、逐位对拍差异日志、边界测试和重现命令。
- 基线/候选优化的内部对照记录与冷/热态标签。官方性能测试要求任务前清空任务/参数缓存，不能用热态结果替换。

这些文档不等于官方验收通过；截图不替代可复现日志。此阶段不生成正式技术协议和综合脚本。

- 完整赛题（本地缺印刷第 1 页）、版本/公告；初决赛日期、提交入口、打包/命名/大小限制、是否另有学校或赛事表单。

- 指定工艺/标准单元库、SRAM 宏仿真与综合/时序/功耗/面积资料、综合工具及合法许可、PVT/电压/温度/负载/互连估计条件、活动覆盖口径；最终工具/库不由本阶段自行选定。
- 老师两份原始 txt 和 FP32 优先、多模式/流水、8×16 阵列及三缓存的阶段约束。此项为教学/团队约束核实，不伪装为官方统一要求。
- 受限平台、工艺库和大型活动文件的正式交付/访问方式；需同时满足竞赛复现要求及资产授权范围。
