## 二、量化格式与软件数值合同

| 数据 | 格式 | 说明 |
|---|---|---|
| 输入 X | signed INT16，Q4.12（`x_frac=12`） | 合法值 [−32767, 32767]，零点 0 |
| 权重 W | signed INT16，Q0.16（`w_frac=16`） | 同上 |
| Bias | signed INT32，Q8.28 | 每通道一个，64 次 MAC 后只加一次 |
| 乘积 | signed INT32 | 16×16 全精度，不截断 |
| 累加 | **signed 48 位**（合同最小 38 位） | 全范围上界 `64×32767² + 2³¹ = 70,862,766,144 < 2³⁷` |
| 输出 Y | signed INT16 | RNE 右移 15/16 位，饱和到 ±32767 |
| 保留码 | `-32768 (0x8000)` | 硬件遇到即拒绝任务 |

逐层指数：layer 00 / 03–10 为 `y_frac=13`（移 15）；layer 01 / 02 / 11 为 `y_frac=12`（移 16）。

**格式依据**：逐层镜像实测 `max|x| = 20,162`、`max|w| = 27,538`，均超出 12 位/10 位容器，因此本设计采用 INT16 全字，而非 A12W10。

**冻结材料**（commit `bbff21cf`）：`int16_frozen_d7329f2.json`（候选 `rtl_int48_fixed`，`acc_bits=48`）、`int16_numeric.py`、`int16_round01.py`、`kwt_reference.py`。模型为官方 KWT-1 `237e4097`，30/30 运行时文件通过 Git blob 校验。

## 三、舍入、饱和与误差处理

- **舍入**：RNE（四舍六入五成双）：`+1/2→0`、`+3/2→2`、`−1/2→0`、`−3/2→−2`。
- **饱和**：输出限 ±32767，`-32768` 永不产生。
- **累加**：48 位，不逐步饱和；bias 最后注入一次。
- **误差分解（layer 00 单样本）**：量化 7.45e-05 + 输出舍入 5.84e-05 → 合计 9.449e-05。
- **量化误差控制**：RNE + 48 位累加，100 样本下 x/w/bias/累加均未出现饱和。

## 四、系统架构与总线接入

```
E203 RISC-V (rv32imc)
  ├─ NICE / 系统总线 ──> u_kwt（int16_accelerator_top）
  │                        ├─ 16 × INT16 MAC
  │                        ├─ 权重缓存 16 × RAMSP128X16（4 KB）
  │                        └─ 控制/状态 + 总线适配
  └─ 共享 SRAM 24 × RAMSP8KX32；ITCM 8 × RAMSP4KX64
```

- 控制寄存器：`0x1100_0000`（bit0 = start）；数据：`0xa000_0000`；y 写回：`0xa004_0000`。
- 加速器通过 `int16_e203_system_bus_adapter` 挂到 E203 系统总线，CPU 以 MMIO 配置与启动，数据搬运由加速器侧 DMA 完成。
- 时钟：`core_clk` 150 MHz（SDC `-period 6.66667`），外部晶振 16 MHz；复位由 `e203_reset_ctrl` 同步产生 `rst_core / rst_itcm / rst_dtcm`。

## 五、数据分块与权重 tile

- 权重缓存：16 bank × 128 word × 16 bit = **4 KB**，bank i ↔ 输出通道 i；
- 单 tile：16 输出通道 × 64 K = 1,024 字 = 2 KB；
- 一层（N = 256）：共 16 个 tile，每个 tile 在 99 个 m 行上复用；
- DMA：`w = 1024` 拍 = 16,384 权重 ÷ 16/拍，与结构自洽；
- 结果写回：99×256 个 INT16，按 32 位字打包，共 12,672 字。

---

## 六、PE 阵列与累加

- 16 路 INT16 MAC：`INT16 × INT16 → INT32` 全精度乘积；
- 48 位有符号累加器，跨 K 分块保持整数部分和；
- bias 在最后注入一次，宽度 INT32，尺度 `2^28`；
- 输出 RNE 右移 + 对称饱和；
- 12 层共用同一阵列，逐层更换参数。
